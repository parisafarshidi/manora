# مانورا — نسخه نمایشی اولیه

## اجرا در ویندوز
۱. ZIP را در پوشه `D:\p\br ai\manora` استخراج کن.
۲. در همان پوشه، نوار آدرس File Explorer را کلیک کن، `powershell` بنویس و Enter بزن.
۳. اجرا کن:

```powershell
npm install
npm run dev
```

۴. آدرس Local که Vite نشان می‌دهد را در مرورگر باز کن (معمولاً `http://localhost:5173`).

## امکانات
- صفحه اصلی فارسی و راست‌چین، واکنش‌گرا و دارای انیمیشن
- ورود آزمایشی با سه نقش: کاربر، متخصص و مدیر
- داشبورد کاربر، پرونده سلامت، ارزیابی نمونه، متخصصان و آموزش
- پنل متخصص نمونه
- پنل مدیر: افزودن/ویرایش/حذف مقاله و افزودن/فعال‌سازی/حذف خدمت
- ذخیره محتوای نمونه در localStorage مرورگر

## هشدار مهم
این فقط یک دمو است؛ احراز هویت واقعی، سرور و پایگاه داده ندارد. اطلاعات پزشکی واقعی وارد نکن. نقش‌ها و مجوزها فقط سمت رابط کاربری هستند؛ برای محصول واقعی باید احراز هویت و کنترل دسترسی سمت سرور، ذخیره‌سازی امن و بررسی امنیتی پیاده‌سازی شود.

فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در نبود اینترنت از فونت جایگزین استفاده خواهد شد.
